# Notícias de Cabo Verde

Site estático em https://noticias.explorecaboverde.com com as principais notícias do dia sobre Cabo Verde.

- `data/edicoes/AAAA-MM-DD.json` — uma edição por dia (atualizada automaticamente todas as manhãs)
- `build.py` — gera o site em `docs/` (`python3 build.py`)
- `docs/` — o que o GitHub Pages publica
